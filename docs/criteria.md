## Method

- **Latency basis:** client-measured latency of each successful query minus the median probe (SELECT 1) round trip of the same run. A run is valid only if probe p50 <= 100 ms and probe p99 - p50 <= 15 ms; an invalid run is discarded and re-run; never scored, never averaged in.
- **Repetitions:** 5 per configuration, level and cache state, baselines interleaved, randomized within each repetition, seed 630, on the held_out (the loop never sees it; ADR 0002, R3).
- **Pooling:** percentiles are computed on observations pooled across the repetitions of one configuration, level and cache state.
- **Interval:** distribution-free binomial order-statistic interval (normal approximation), pocbench.stats.quantile_ci, 95%.
- **Spread:** every criterion also reports the per-repetition values and their spread, (max - min) / median.
- **Noise:** if a baseline's spread is at least 20%, comparisons against that baseline are inconclusive (not met).
- **Under-sampled:** a percentile is supported when the pooled observations and the distinct instances beyond it reach the floors (load model, ADR 0018). An unsupported percentile in a ceiling criterion makes it unsupported (not met). A no-regression comparison uses the highest percentile supported on both sides, falling back p99, p95, p50.

Verdicts:

- **ceiling:** met if the interval's upper bound <= ceiling; failed if its lower bound > ceiling; otherwise inconclusive (not met)
- **no regression:** met if candidate upper bound <= (1 + tolerance) x baseline upper bound; failed if candidate lower bound > (1 + tolerance) x baseline upper bound; otherwise inconclusive (not met)
- **error ceiling:** pooled (errors + timeouts) / observations
- **throughput floor:** median across repetitions of successful queries per second
- **cost ceiling:** pooled CU x cu_hour_usd x measured seconds / 3600 / successful queries
- **recommendation:** every criterion met; otherwise the candidate fails and the output may be a refusal (ADR 0011)
- **mix level:** mix-level numbers are reported, never scored (R12)
